# Recruiters

Every recruiter has their own note (tagged `recruiters`, created from [[Templates/Recruiter Contact|the Recruiter Contact template]]). The table below is generated from those notes, so edit the frontmatter in the individual note and this page updates itself.

> **Cadence:** contact a minimum of **3 recruiters a week**. Follow up **once a week** on anyone who's gone quiet. If there's been **no response after 2 weeks**, stop chasing that person and reach out to someone else at the same company instead.


![[recruiters.base]]

## Weekly Recruiter Loop

1. **Find** — identify 3+ new recruiters/agencies working roles in your target areas .
2. **Reach out** — send the [[Email Templates#Recruiter — Initial Outreach|initial outreach message]] referencing a specific role you applied to.
3. **Log it** — create a note in this folder (the Recruiter Contact template runs automatically and asks for their name and agency), fill in `first_contact`, `last_contact` and `next_follow_up` (+7 days), and set `status: contacted`. It shows up in the table automatically.
4. **Follow up weekly** — use the [[Email Templates#Recruiter — Weekly Follow-Up|follow-up template]] until you get a response, then update `last_contact` and `next_follow_up` in the note.
5. **2-week rule** — the Action column shows **Switch contact** once 14 days have passed since first contact. Set `status: no response - moved on` and find a different contact at that agency.

## Status Values

Use these in each note's `status` field, since the Action column reads them:
`contacted` · `replied` · `in conversation` · `interviewing` · `no response - moved on`
